# Beamline Example Data

This is simply a text file to link example data sets from various beamlines: the intent here is to give a source where data can be pulled for software testing. Ultimately this should include _live_ updates on what software has been verified to work with each of the example data sets and some commentary on the extent to which that data agrees with the conventions / standards.

| -------- | -------- | -------- | ------------- | ---------------------| --------| 
| DLS      | I24      | JF1M     | https://zenodo.org/records/15017658 | Jungfrau 1M example data set | beta |

To contribute examples please fork this repo, edit the markdown and make a PR.
